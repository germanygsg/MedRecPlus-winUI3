Inter 4.1 by The Inter Project Authors.

Source: https://github.com/rsms/inter/releases/tag/v4.1

The unmodified variable fonts include the full weight range, with upright and
italic faces. WinUI loads the bundled family from `ms-appx:///Assets/Fonts/InterVariable.ttf#Inter Variable`.
No system font installation or network connection is required.
